# Mixed friend addition

This is a review lesson, not a new friend rule. Choose a valid direct, 5-friend, or 10-friend sequence for each rod, and keep track of any carry into the next place. For +6 through +9, the 10-friend is often the shortest route.

## Example: 7 + 6

1. Use **+10 −4**. Remove 4 from 7 with the 5-friend move **−5 +1**, leaving 3 on the ones rod.
2. Add 1 to the tens rod to account for the ten: the rods now show 13.

Check that each intermediate move is possible. Different bead states can make another valid sequence more convenient.

## Practice

Try 8 + 6, 9 + 7, 16 + 8, and 27 + 6. Say each intermediate value as you move.
