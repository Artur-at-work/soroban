# Direct addition

Add directly when the needed beads are already available on that rod. Move one earth bead up for +1, two for +2, and so on. If the upper bead is away from the beam, it can also move down for +5.

{% include soroban.html rods=2 value=2 label="Try 2 + 2" %}

## Example: 2 + 2

1. Set 2 on the ones rod.
2. Move two earth beads up to the beam.
3. Read 4. No other rod changes.

For a direct +1 to +4, the number of active earth beads plus the amount added must be at most 4. Pause when the next bead is not available; the friend methods handle that case.

## Practice

Try 1 + 3, 3 + 1, 0 + 4, and 12 + 1. Say the result before checking it on the board.
